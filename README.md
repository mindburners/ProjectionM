# Projection Mapper

Simple Android projection mapping: Square, Circle, Triangle and Freeform shapes, each filled with an image or video.

## Get the APK (no Android Studio needed)
1. Create a new GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab. The "Build APK" job runs automatically (about 3 minutes).
3. Open the finished run and download **ProjectionMapper-apk** under Artifacts. Unzip it to get `app-debug.apk`.
4. Copy the APK to the phone and open it. Allow "install unknown apps" for your file manager when Android asks.

To change the app, edit `app/src/main/assets/index.html` and push. A new APK builds each time.

## Browser version
The `web` folder is the same app for GitHub Pages. Opened in Chrome, use the menu → **Install app**.
